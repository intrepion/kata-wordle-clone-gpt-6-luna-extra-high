# Wordle

A small, dependency-free daily word puzzle for the browser. Guess the five-letter word in six tries; the board gives green, gold, and gray clues after each guess.

## Play

Open `index.html` in a browser, or serve this folder with any static file server. The puzzle, keyboard input, daily save, statistics, share grid, hard mode, dark theme, and high-contrast colors run entirely in the browser.

The daily answer is selected from a curated list of common five-letter words using the local calendar date. Your guesses and settings are saved in local storage on this device.

## Word list

Accepted guesses use the five-letter entries from [Tab Atkins Jr.'s wordle-list](https://github.com/tabatkins/wordle-list), distributed under the MIT license in [WORD-BANK-LICENSE.txt](WORD-BANK-LICENSE.txt). The answer list is a smaller curated subset.
